# 📊 Pesquisa de Opinião

Projeto desenvolvido em **Python** para realizar uma pesquisa de opinião com 50 pessoas e identificar a quantidade de respostas classificadas como **Excelente** e **Ruim**.

## 🎯 Objetivo

O programa solicita o **nome**, a **idade** e a **opinião** de cada participante sobre o atendimento.

As opções de resposta são:

* ⭐ **1 - Excelente**
* 👍 **2 - Bom**
* 👎 **3 - Ruim**

Ao final da pesquisa, o programa informa a quantidade de pessoas que avaliaram o atendimento como **Excelente** e **Ruim**.

## 🔄 Estrutura utilizada

Foi utilizada a estrutura de repetição for, pois a pesquisa possui uma quantidade definida de 50 entrevistados. Dessa forma, o programa consegue repetir as perguntas exatamente 50 vezes.

A cada resposta, são utilizadas estruturas de decisão (if e elif) para verificar a opinião informada:

* Se a opinião for `1`, o contador de respostas **Excelente** aumenta em 1.
* Se a opinião for `3`, o contador de respostas **Ruim** aumenta em 1.

## ▶️ Como executar

1. Tenha o **Python 3** instalado no computador.
2. Baixe ou clone este repositório.
3. Abra a pasta do projeto.
4. Execute o arquivo:

```bash
python pesquisa_opiniao.py
```

5. Informe os dados solicitados pelo programa.
6. Após as 50 respostas, serão exibidas as quantidades de avaliações **Excelente** e **Ruim**.
